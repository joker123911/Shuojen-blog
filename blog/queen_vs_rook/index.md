王＋后對王＋車，理論上**白方必勝**，但實戰一點都不簡單：黑車只要待在黑王旁邊，后就很難直接吃到它，而且黑方一有機會就會用車**一直將軍**或**送車逼和**。

這種殘局最重要的局面叫 **Philidor 局面**：黑王在底線、黑車擋在王前面；白王站在黑車的斜前方攻擊它，白后跟白王差**一個馬步**（c6 和 a5）。

你執白，想辦法吃掉黑車或直接殺王，試試看吧！

## 勝法說明

這個局面如果**輪到黑方走**，黑方就**沒有好棋**（Zugzwang，被迫走棋）：黑王動不了，黑車不管走到哪裡都會被后**將軍抽車**或直接殺王。

可惜現在是**白方先走**，所以白方要想辦法**把走棋權丟給黑方**：

- **后三角移動**：1.Qe5+ 將軍，黑王只能去 a8；2.Qa1+ 再將軍，黑王回到 b8；3.Qa5 后回到原來的格子。
- 三步之後，局面跟一開始**一模一樣**，只是變成**輪到黑方走**。
- 黑車離開黑王，后就**連續將軍**，最後一次將軍同時攻擊黑王和黑車（**抽車**），吃掉車之後回到[單后殺王](/blog/2026/11/16/queen_mate)。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 w - - 0 1"]
1. Qe5+ Ka8 2. Qa1+ Kb8 3. Qa5 Rb1 4. Qe5+ Ka7 5. Qd4+ Ka8 6. Qh8+ Ka7 7. Qh7+ Kb8 8. Qxb1+ Kc8 9. Qb4 Kd8 10. Qf8#`} />

:::tip[為什麼不直接吃車？]
黑車在黑王旁邊，有黑王保護。后對車要贏，靠的不是硬吃，而是**等黑車離開黑王**，再用將軍同時攻擊王和車。
:::

## 黑方的其他走法

輪到黑方走的 Philidor 局面，黑方怎麼走都會輸，常見的有下面幾種：

**車沿著橫線跑遠**：后連續將軍，把黑王趕到車的反方向，最後在 h7 將軍抽車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rh7 2. Qe5+ Ka7 3. Qa1+ Kb8 4. Qb1+ Ka7 5. Qxh7+ Ka6 6. Qb1 Ka5 7. Qb5#`} />

**車沿著直線往下走**：2.Qe5+ 將軍黑王，同時攻擊 b2 的車，黑王躲開之後就吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rb2 2. Qe5+ Ka7 3. Qxb2 Ka6 4. Qa1#`} />

**黑王離開**：2.Qa6 **牽制**黑車，車不能離開 b7，下一步就直接吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Kc8 2. Qa6 Kd8 3. Qxb7 Ke8 4. Qg7 Kd8 5. Qd7#`} />

## 小心逼和

黑方最大的機會是**逼和**：黑王被關在角落、自己已經沒有棋可以走的時候，黑車只要**送給白方吃**，就是和棋。

下面這個局面，白后 c7 已經把黑王關死了，黑方走 1...Rb6+!，白王吃車之後黑方**沒有任何合法的走法**，逼和。白王不吃車的話，黑車就繼續跟著白王一直將軍。

<Black pgn={`[FEN "k7/2Q5/2K5/8/8/8/1r6/8 b - - 0 1"]
1... Rb6+ 2. Kxb6`} />

:::tip[收網前先檢查]
把黑王逼到角落時，先想一想：**黑車送給我吃，黑王還有沒有棋走？** 沒有的話，就先換一步，讓黑王留一個空格。
:::

## 系統化的走法：怎麼走到 Philidor 局面

黑王、黑車都在中間的時候，不可能馬上抽車。白方的計畫分成三步：

1. **把黑王趕到邊線**。
2. 黑方退到角落、把車擋在王前面時，**擺出 Philidor 局面**。
3. 黑方不肯進角落時，**封住黑王，逼黑車離開**，再抽車。

下面的例子都在同一個角落（棋盤左上角），最後對準開頭的 Philidor 局面。

### 步驟一：把黑王趕到邊線

先記住幾個原則：

- **黑車會一直待在黑王旁邊**：黑車有黑王保護，后就吃不到；不要急著吃車，**Qxe5+ 這種吃車常常是送后**。
- **白王一直往前走**：跟[單車殺王](/blog/2026/11/17/rook_mate)一樣，白王盡量跟黑王**對王**（面對面、中間隔一格），黑王才不敢往前。
- **后從遠處、從斜線將軍**：后離黑王遠一點，黑王就碰不到后；每一次將軍都把黑王**往後推**，讓白王有時間跟上。
- **白王能攻擊黑車就攻擊**：黑車被趕來趕去，就沒空將軍。
- **黑車將軍時往前躲**：白王往黑王那一側躲，不要往後退。

先把黑王推出中間：后連續將軍，黑王每退一步，白王就往前一步（Kd2、Kd3、Kd4），最後白王站到正中央。

<White pgn={`[FEN "8/8/8/3kr3/8/8/8/3KQ3 w - - 0 1"]
1. Qh1+ Kd4 2. Kd2 Rf5 3. Qg1+ Ke4 4. Qe3+ Kd5 5. Kd3 Rf1 6. Qe4+ Kd6 7. Qg4 Rb1 8. Qf4+ Kd5 9. Qa4 Kd6 10. Kd4 Rg1`} />

再把黑王往左上角趕：后繼續將軍，白王跟在後面（Kc4、Kb4、Kb5）。黑車從旁邊將軍時，白王都是**往前躲**（Kb4、Kc5）。最後黑方走 Rb7，把車放回黑王旁邊。

<White pgn={`[FEN "8/8/3k4/8/Q2K4/8/8/6r1 w - - 0 1"]
1. Qa3+ Kd7 2. Qh3+ Kc6 3. Qf3+ Kb5 4. Qd3+ Kc6 5. Kc4 Rc1+ 6. Kb4 Kb7 7. Kb5 Kc7 8. Qe3 Rb1+ 9. Kc5 Rb7`} />

黑王被擠到最後兩排、黑車擋在黑王旁邊，接下來看黑王**有沒有退到角落**。

### 步驟二：黑王退到角落，擺出 Philidor 局面

黑王躲進 a8、黑車擋在 b7 的時候，就是要走成 Philidor 局面的時機：

- **白王走到 c6**：站在黑車的斜前方，攻擊黑車，黑王只能守著車。
- **后跳到白王的馬步位置**：后從底線將軍，把黑王趕到 a7，再走 **Qa5+**（跟 c6 的白王差一個馬步），黑王只能回到 b8。
- 這樣就是開頭的 **Philidor 局面（白先）**，接著用**后三角移動**（Qe5+、Qa1+、Qa5）把走棋權丟給黑方。

下面黑方每一步都是殘局庫的最佳防守：

<White pgn={`[FEN "k7/1r6/2K5/8/8/8/8/3Q4 w - - 0 1"]
1. Qd8+ Ka7 2. Qa5+ Kb8 3. Qe5+ Ka8 4. Qa1+ Kb8 5. Qa5`} />

走完 5.Qa5，就是**輪到黑方走的 Philidor 局面**，黑車不管走到哪裡都會被抽掉（見上面的〈黑方的其他走法〉）。

:::tip[認局面的口訣]
**白王攻擊黑車、白后在白王的馬步位置**。局面歪掉、換到別的角落也一樣，先把王和后擺成這個形狀，輪到白方走就三角移動。
:::

### 步驟三：黑王不進角落，封住它

黑方最頑強的防守是**不進角落**，黑王留在 c7、黑車守在 b7。這時候：

- **Qe8!**：后封住第 8 橫線和 d7，b6、c6、d6 又被白王擋住，**黑王一步都動不了**，黑方只好移動黑車。
- 黑車一離開黑王，后就將軍、白王再往前，黑車又被逼著移動。
- 黑車跑到 a2，**Qd5+** 同時將軍黑王、攻擊 a2 的車，抽車，接下來就是單后殺王。

<White pgn={`[FEN "8/1rk5/8/2K5/8/4Q3/8/8 w - - 0 1"]
1. Qe8 Ra7 2. Qe5+ Kb7 3. Kb5 Ra2 4. Qd5+ Kc7 5. Qxa2 Kd6 6. Qh2+ Ke6 7. Qf4 Kd5 8. Kb6 Ke6 9. Kc6 Ke7 10. Qf5 Ke8 11. Kd6 Kd8 12. Qd7#`} />

:::tip[小心串打]
白王和白后**不要排在同一條直線或橫線上**。黑車從那條線將軍，白王一躲開，后就被黑車吃掉了。白王盡量站在黑王的**斜對面**，比較不會被黑車找到將軍。
:::

## 挑戰：從中間開始

學會三個步驟之後，從頭試一次！殘局庫最佳下法要 **31 步**才殺得了。

注意 e5 的黑車有黑王保護，**Qxe5+ 吃車就直接和棋了**。

<QueenVsRookBoard fen="8/8/8/3kr3/8/8/8/3KQ3 w - - 0 1" />

照正常規則下，50 步內沒有吃子就是和棋，所以要邊下邊注意步數！
