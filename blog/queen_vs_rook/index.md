王＋后對王＋車，理論上**白方必勝**，但實戰一點都不簡單，黑車只要待在黑王旁邊，后就很難直接吃到它，而且黑方一有機會就會用車**一直將軍**或**送車逼和**。

先從我們想要形成的目標 **Philidor 局面**開始：黑王在底線、黑車擋在王前面，白王跟黑王面對面。

你執白，想辦法吃掉黑車或直接殺王，試試看！

<QueenVsRookBoard />


## 勝法說明

這個局面如果**輪到黑方走**，黑方就**沒有好棋**（Zugzwang，被迫走棋）：黑王動不了，黑車不管走到哪裡都會被后**將軍抽車**或直接殺王。

可惜現在是**白方先走**，所以白方要想辦法**把走棋權丟給黑方**：

- **后三角移動**：1.Qe5+ 將軍，黑王只能去 a8；2.Qa1+ 再將軍，黑王回到 b8；3.Qa5 后回到原來的格子。
- 三步之後，局面跟一開始**一模一樣**，只是變成**輪到黑方走**。
- 黑車離開黑王，后就**連續將軍**，最後一次將軍同時攻擊黑王和黑車（**抽車**），吃掉車之後回到[單后殺王](/blog/2026/11/16/queen_mate)。

## 黑方的其他走法

輪到黑方走的 Philidor 局面，黑方怎麼走都會輸，常見的有下面幾種：

**車沿著橫線跑遠**：后連續將軍，把黑王趕到車的反方向，最後在 h7 將軍抽車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rh7 2. Qe5+ Ka7 3. Qa1+ Kb8 4. Qb1+ Ka7 5. Qxh7+ Ka6 6. Qb1 Ka5 7. Qb5#`} />

**車沿著直線往下走**：2.Qe5+ 將軍黑王，同時攻擊 b2 的車，黑王躲開之後就吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rb2 2. Qe5+ Ka7 3. Qxb2 Ka6 4. Qa1#`} />

**黑王離開**：2.Qa6 **牽制**黑車，車不能離開 b7，下一步就直接吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Kc8 2. Qa6 Kd8 3. Qxb7 Ke8 4. Qg7 Kd8 5. Qd7#`} />

## 小心逼和

黑方最大的機會是**逼和**：黑王被關在角落、自己已經沒有棋可以走的時候，黑車只要**送給白方吃**，就是和棋。

下面這個局面，白后 c7 已經把黑王關死了，黑方走 1...Rb6+!，白王吃車之後黑方**沒有任何合法的走法**，逼和。白王不吃車的話，黑車就繼續跟著白王一直將軍。

<Black pgn={`[FEN "k7/2Q5/2K5/8/8/8/1r6/8 b - - 0 1"]
1... Rb6+ 2. Kxb6`} />

:::tip[檢查]
把黑王逼到角落時，先想一想：**黑車送給我吃，黑王還有沒有棋走？** 沒有的話，就先換一步，讓黑王留一個空格。
:::

## 挑戰：從中間開始

黑王、黑車都在中間的局面就更難了。先用后**將軍、王慢慢靠近**，把黑王趕到邊線，再想辦法走成 Philidor 局面。

<QueenVsRookBoard fen="8/8/8/3rk3/8/8/8/3QK3 w - - 0 1" />

照正常規則下，50 步內沒有吃子就是和棋，所以要邊下邊注意步數！
