王＋后對王＋車，理論上**白方必勝**，但實戰一點都不簡單：黑車只要待在黑王旁邊，后就很難直接吃到它，而且黑方一有機會就會用車**一直將軍**或**送車逼和**。

這種殘局最重要的局面叫 **Philidor 局面**：黑王在底線、黑車擋在王前面；白王站在黑車的斜前方攻擊它，白后跟白王差**一個馬步**（c6 和 a5）。

你執白，想辦法吃掉黑車或直接殺王，試試看吧！

## 勝法說明

這個局面如果**輪到黑方走**，黑方就**沒有好棋**（Zugzwang，被迫走棋）：黑王只能走到 c8，但這樣黑車就會被后牽制；黑車不管走到哪裡都會被后**將軍抽車**或直接殺王。

可惜現在是**白方先走**，所以白方要想辦法**把走棋權丟給黑方**：

- **后三角移動**：1.Qe5+ 將軍，黑王去 a8 或 a7（走 c8 會被 Qe8 直接殺王）；2.Qa1+ 再將軍，黑王回到 b8；3.Qa5 后回到原來的格子。
- 三步之後，局面跟一開始**一模一樣**，只是變成**輪到黑方走**。
- 黑車離開黑王，后就**連續將軍**，最後一次將軍同時攻擊黑王和黑車（**抽車**），吃掉車之後回到[單后殺王](/blog/2026/11/16/queen_mate)。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 w - - 0 1"]
1. Qe5+ Ka8 2. Qa1+ Kb8 3. Qa5 Rb1 4. Qe5+ Ka7 5. Qd4+ Ka8 6. Qh8+ Ka7 7. Qh7+ Kb8 8. Qxb1+ Kc8 9. Qb4 Kd8 10. Qf8#`} />

:::tip[為什麼不直接吃車？]
黑車在黑王旁邊，有黑王保護。后對車要贏，靠的不是硬吃，而是**等黑車離開黑王**，再用將軍同時攻擊王和車。
:::

## 黑方的其他走法

輪到黑方走的 Philidor 局面，黑方怎麼走都會輸，常見的有下面幾種：

**車沿著橫線跑遠**：后連續將軍，把黑王趕到車的反方向，最後在 h7 將軍抽車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rh7 2. Qe5+ Ka7 3. Qa1+ Kb8 4. Qb1+ Ka7 5. Qxh7+ Ka6 6. Qb1 Ka5 7. Qb5#`} />

**車沿著直線往下走**：2.Qe5+ 將軍黑王，同時攻擊 b2 的車，黑王躲開之後就吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rb2 2. Qe5+ Ka7 3. Qxb2 Ka6 4. Qa1#`} />

**黑王離開**：2.Qa6 **牽制**黑車，車不能離開 b7，下一步就直接吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Kc8 2. Qa6 Kd8 3. Qxb7 Ke8 4. Qg7 Kd8 5. Qd7#`} />

## 小心逼和

黑方最大的機會是**送車逼和**：黑王已經沒有棋可以走的時候，黑車只要衝過來讓白方吃，吃了就是和棋。

例如 Philidor 局面白方想直接 1.Qa6 把黑王關住，黑方 1...Rb6+!，這時候**白王不能吃車**：吃了之後黑王**沒有任何合法的走法**，逼和。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 w - - 0 1"]
1. Qa6 Rb6+ 2. Kxb6`} />

:::tip[收網前先檢查]
每走一步之前先想一想：**黑車送給我吃，黑王還有沒有棋走？** 沒有的話，就換一步。
:::

## 系統化的走法：一層一層把黑車往後逼

黑車要待在黑王附近才不會被抽掉，所以黑方的防守，看的是**黑車守在第幾條橫線**（從黑方那一邊數）：

- **第二橫線防守**：黑車在第 7 橫線，緊貼著黑王。Philidor 局面就是這一種。
- **第三橫線防守**：黑車在第 6 橫線。
- **第四橫線防守**：黑車在第 5 橫線，最難對付。

黑車站得越前面，白王越難靠近。白方的計畫是**一層一層往後逼**：

**第四橫線 → 第三橫線 → 第二橫線 → Philidor 局面**

每一層用的方法都一樣：

- **白王往黑車走**：白王攻擊黑車，黑車只好往黑王那邊退一條橫線。
- **后負責將軍、卡位置**：后不讓黑王往前走。輪到白方走、卻沒有好棋的時候，就用后走一步「等著」，把走棋權丟給黑方（Zugzwang）。
- **黑車一離開黑王就抽車**：后用直線、橫線、斜線連續將軍，找機會同時攻擊黑王和黑車。
- **一路上都要小心**：送車逼和、白王和后被黑車串打。

下面從最接近 Philidor 局面的第二橫線防守開始看。

### 第二橫線防守

黑王在 c8、黑車在 e7 守第二橫線。白方要把黑王**趕進角落**，走成 Philidor 局面：

- **1.Qf5+**：先把后拉開一點將軍，黑王退到 d8。
- **2.Kc5!**：白王往前走，這是殘局庫的最佳走法。如果走 2.Kc6，要小心黑方 2...Re6+!，**白后不能吃車**，吃了就是逼和（見下面的棋譜）。
- 白王往 b5、c6 走，后在 e5、e8、e4 卡住黑王。**6.Qe8!** 和 **7.Qe4** 都不是將軍，只是讓黑方先走，黑方每一步都讓局面更糟。
- **9.Qd5** 之後黑王走 b8，**10.Qa5** 就是開頭的 Philidor 局面，而且**輪到黑方走**。

<White pgn={`[FEN "2k5/4r3/1K6/3Q4/8/8/8/8 w - - 0 1"]
1. Qf5+ Kd8 2. Kc5 Kc7 3. Qd5 Rd7 4. Qe5+ Kb7 5. Kb5 Rc7 6. Qe8 Ka7 7. Qe4 Rb7+ 8. Kc6 Ka8 9. Qd5 Kb8 10. Qa5`} />

2.Kc6? 的逼和陷阱：

<White pgn={`[FEN "2k5/4r3/1K6/3Q4/8/8/8/8 w - - 0 1"]
1. Qf5+ Kd8 2. Kc6 Re6+ 3. Qxe6`} />

:::tip[Philidor 的前一步]
記住 9.Qd5 之後的局面：黑王 a8、黑車 b7，白王 c6、白后 d5，輪到黑方走。黑王走 b8 就 **Qa5**，黑王走 a7 就 **Qd8**，兩種都是**輪到黑方走的 Philidor 局面**。

Qd8 那一種是把開頭的局面沿著斜線翻過來，看起來不一樣，其實是同一個形狀：**白王攻擊黑車、白后在白王的馬步位置**。實戰中局面可能出現在任何方向，要練到每個方向都認得出來。
:::

1... Ka7 2. Qd8`} />

### 第三橫線防守

黑車在 b6 守第三橫線，白王過不去 c6。輪到白方走，可是怎麼走都沒有進展，那就**把走棋權丟給黑方**：

- **1.Qf4!**：什麼都沒威脅，只是等黑方走。黑車不能沿著第六橫線跑開：1...Ra6 有 2.Qb8+ 接 Qb7+；1...Rg6 有 2.Qf8+ 接 Qf7+，都是**將軍抽車**。
- 黑王往前 **1...Kd7**，后就**換個角度將軍**：2.Qa4+ 從斜線、3.Qa7+ 從橫線。黑方最頑強的是 3...Rb7 擋住，**退到第二橫線**（黑王走 c8、d8 會輸得更快）。
- 白王馬上往前（Kd6、Kc6），后一路將軍，最後在 e4 卡住黑王。黑車回到 b7 時，用**后三角移動**（Qe5+、Qa1+、Qa5）走成輪到黑方走的 Philidor 局面。

<White pgn={`[FEN "3k4/5Q2/1r6/3K4/8/8/8/8 w - - 0 1"]
1. Qf4 Kd7 2. Qa4+ Kc7 3. Qa7+ Rb7 4. Qc5+ Kb8 5. Kd6 Rg7 6. Qb6+ Kc8 7. Qc6+ Kb8 8. Qe8+ Kb7 9. Qe4+ Kb8 10. Kc6 Rb7 11. Qe5+ Ka8 12. Qa1+ Kb8 13. Qa5`} />

黑車沿著橫線跑開，就會被抽掉：

1... Ra6 2. Qb8+ Ke7 3. Qb7+ Kf6 4. Qxa6+`} />

1... Rg6 2. Qf8+ Kc7 3. Qf7+ Kb6 4. Qxg6+`} />

### 第四橫線防守

黑車在 a5 守第四橫線，是最難破的防守，但方法還是一樣：**白王往黑車走，逼黑車退後**。

- **1.Qf7+**：先將軍，看黑王往哪裡走。接著 2.Qe8、3.Qe6，后從上面壓住黑王，黑王不能往前。
- **白王往黑車走**：Kd4、Kc4，下一步就要到 b4 攻擊 a5 的黑車。
- 黑車想沿著第五橫線跑到另一邊（g5、h5），很快就會被后連續將軍抽掉（例如 5...Rg5 6.Qe7+）。黑車可以 **5...Ra7**，**直接退到第二橫線**。
- 6.Kb5 之後，就照上面〈第二橫線防守〉的方法收網。

<White pgn={`[FEN "8/3k4/5Q2/r7/4K3/8/8/8 w - - 0 1"]
1. Qf7+ Kd6 2. Qe8 Kc7 3. Qe6 Rb5 4. Kd4 Ra5 5. Kc4 Ra7 6. Kb5`} />

殘局庫最頑強的防守其實是 **5...Ra2**：黑車乾脆跑到遠處，從後面將軍。這時候黑車已經離開黑王，白方就照〈黑方的其他走法〉的思路：后連續將軍把黑王趕回底線，白王跟上擋住黑車的將軍，最後找到同時攻擊黑王和黑車的將軍，抽車。

<White pgn={`[FEN "8/3k4/5Q2/r7/4K3/8/8/8 w - - 0 1"]
1. Qf7+ Kd6 2. Qe8 Kc7 3. Qe6 Rb5 4. Kd4 Ra5 5. Kc4 Ra2 6. Qe5+ Kc6 7. Qc3 Ra6 8. Qf6+ Kb7 9. Qe7+ Kb6 10. Qc5+ Kb7 11. Kb5 Ra1 12. Qd5+ Kc8 13. Kb6 Rb1+ 14. Kc6 Rc1+ 15. Kd6 Kb8 16. Qb3+ Kc8 17. Qa3 Rd1+ 18. Kc6 Kb8 19. Qb3+ Kc8 20. Qxd1`} />

:::tip[白王別擋住后]
白王靠近的時候，別站在后將軍、攻擊黑車的路線上。影片提到，有時候白王走 Kd3 比 Kd4 好，就是為了讓后保有直線、斜線的將軍。
:::

## 挑戰：從中間開始

學會四層防守之後，從頭試一次！先用后將軍把黑王趕到邊線，看黑車守在第幾橫線，再一層一層往後逼。殘局庫最佳下法要 **31 步**才殺得了。

注意 e5 的黑車有黑王保護，**Qxe5+ 吃車就直接和棋了**。

<QueenVsRookBoard fen="8/8/8/3kr3/8/8/8/3KQ3 w - - 0 1" />

照正常規則下，50 步內沒有吃子就是和棋，所以要邊下邊注意步數！
