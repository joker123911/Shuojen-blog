## LLM

大概去年九月左右，手機壽終正寢，於是我換了 S25 這隻[手機](/blog/2026/10/04/phone)。

當時換手機有一個活動，直接送了半年還一年的 Gemini Pro 的方案，當時我對 LLM 還一無所知，也就是因為這個契機，直接運用 AI 從零開始架了這個部落格，發了[第一篇貼文](/blog/First_blog)。

一開始我是用從小到大學東西的管道來架網站──看 YouTube。但是架網站這種事情真的太客製化，太難統一每個人的狀況了，所以真的有點難以適應，當我有點卡關的時候，想到不如直接截圖問看看 AI 吧，沒想到令我驚為天人，不管什麼問題都可以跟這位手把手教學的老師，慢慢一步一步試到好。當時的我還不知道 Agent 是什麼，光是用笨的要死的模型（還是比我聰明）來回一直對話自行修改，就讓我覺得超級厲害了。

現在發現當時手機的活動實在辦得太成功，抓到了我這個滿意客戶，在活動到期後還一路續訂到了現在。而且在我發現了[ Antigravity ](/blog/2026/05/22/aseprite#%E5%BE%8C%E8%A8%98)直接操作 Agent 的用法之後，體驗又更上一層樓，完全回不去了。

## Claude

雖然一直聽到 Claude 很厲害，但是習慣成自然實在太可怕，一直都沒有想要換的衝動。直到前兩天想說訂來玩看看好了，下個月再考慮留哪一個。結果真的太驚人，Claude Opus 5.5 的效果實在出奇的好，執行指令的精確度、速度都讓我相當滿意，就連精簡不廢話的語氣都更符合我的胃口。而且在終端機跟 VSCodium 裡操作，我也覺得完全沒有操作與轉換上的難度[^1]，真的相見恨晚。

Token 用量對我來說 Pro 方案也夠用了。長駐使用 Opus 5.5 medium 來處理工作以及維護這個部落格的程式碼，也不太會有見底的用量焦慮。偷偷小改版了部落格上的幾個頁面，[`/archive`](/blog/archive)、[`/guestbook`](/guestbook)、[`/photography`](/photography)、[成語迷宮遊戲](pathname:///game.html)，真的太開心了。

總算過足了[「改網頁」](/blog/2026/11/08/docusaurus#後記)的乾癮。

## 後記

提到看 YouTube，仔細想想，我的興趣好像幾乎都是看 YouTube 學來的。從小學的魔術方塊，高中時學吉他，大學玩水族、學檔車、玩攝影，研究所學下西洋棋，都是「看」來的，中文的內容不夠看就看英文的。

這也變相產生了一個奇怪的現象，我的英文理應明明只有國中程度才對。因為我超討厭英文課，整個高中每堂英文課我都直接睡過去，但是大學後看了很多魔術方塊之類的英文 YouTube 影片，所以我的聽力比閱讀好很多。口說又因為常常聽的緣故，所以即使單字量很破，實際說起來好像又還過得去。

大學時裸考多益甚至出現聽力比閱讀高兩倍的怪異現象（通常大家都相反），雖然也還是只有 600 多分，我的英文還是很爛（想考高分請讀書）。語言這種東西，認真說好像還是得多少背一點單字才行，畢竟我從國中後就再也沒「學」過英文了。

[^1]:唯一有讓我苦惱的是，一開始不知道怎麼貼上截圖，結果就在跑指令的時候，下方直接出現提示：<kbd>Alt</kbd> + <kbd>V</kbd>可以貼上截圖，天哪 Claude 你會讀心嗎！
