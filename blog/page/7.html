與我有關的博客閱讀周記

2026年4月11日 · 閱讀時間約 5 分鐘 · 1215 字
備註

這篇文章受 Marcus 的〈博客閱讀周記〉啟發並效法。

這幾天在 RSS 上有好多部落格朋友的互動，產生了不少共鳴真的很開心，於是啟發了我寫一篇互動回應文。

Alex hsu：〈你的RSS文章壽命可能只有別人的一半〉​

非常感謝 Alex 發現這個問題，真的完全沒有注意到，還特別提醒一樣有這個問題的大家，實在是太暖了！於是我趕緊的來寫這篇文章實際測試看看。

我最後選擇的方式是用 scripts 幫我當天的文章直接加上 date，我覺得這樣更快，如果有各種昨日、明日等等特殊的發佈情況，我就直接手動 key 就好了，這種情況對我來說很少，所以我覺得不需要自動化也無妨。

LQ7：〈我的部落卷（精裝版）（一）〉​

LQ7 大大發了一整篇專屬於我的介紹文章耶，原本看到第一個是自己已經很驚喜了，沒想到整篇只有我，迫不及待想看下一篇的介紹了，有點讓我想到 Alex 大這篇介紹 Derek Sivers 的文章一樣。

超級詳細的推薦，讓我都不好意思了，寫部落格能有這麼好的公開回饋，我願意寫一輩子！

因為知道 LQ7 大大是 MyGo!!!!! 的專家，所以玩一下梗哈哈哈，他寫的 MyGo!!!!! 的二創小說，真的超厲害，作品看起來非常精緻漂亮，真的好用心阿，我要來好好拜讀一下！

我們在興趣上真的很多共通點耶，太神奇了，部落格就是這麼奇妙，能讓素昧平生的陌生人變成朋友，而且中間沒有透過任何演算法喔！

Alex hsu：〈用CSS自動添加中英數字之間的空格〉​

看到這篇的我特別有共鳴！去年的我就寫了一篇〈中文文案排版〉，因為我覺得自己的文字格式很差1，還花了好一番功夫最後養成了這個習慣，但思考過後，我還是沒有選擇跟進，原因有幾點。

  1. 瀏覽器相容性：不支援的瀏覽器上，文字會全部擠在一起，我不想要有可能出現這種體驗。

  2. RSS：在文中也有提到，RSS 不支援的問題。

  3. 我的寫作習慣：我已經習慣這種方式了，我也覺得這樣不會不好看，加上我懶得把前面的文章再改掉空格了（懶是主因吧！）

廢文小天地：〈幫電影打分數有什麼好處？〉​

我第一次知道 z-score 這個個人評分的機制，又學到了一課，每次看廢文小天地，都能學到好多超級「不廢」的知識。

這裡我想來推坑大家都建立自己的音樂、電影等等排名機制，這樣才能最客製化的大推自己的偏好阿！看 IMDB 有什麼意思，這也只是全球觀眾的偏好而已，如果能找到一個跟自己品味相同的知己，直接看他的清單就更準了對吧。

這裡推一個寶藏 Youtube 頻道 * cari me around *，裡面很多電影和書的推薦，當初一看就馬上知道她的電影口味跟我的電波很合了！

JN：〈嘸蝦米使用七個月成果，要怎麼樣才能打快？簡碼要怎麼記？〉​

JN 大非常詳細的教學了嘸蝦米的打字技巧，讓我相當感動！

其實在我研究嘸蝦米的這段時間，大部份的技巧我都知道了，也曾經想要自己整理一篇像這樣的筆記，但苦於表達差以及「懶」，遲遲沒有下定決心來寫，所以看到大大這篇文實在是太驚喜了。

一來是：我不用自己造輪子了，二來是：能夠在陌生人的身上，看到彼此都熱衷和研究同樣的東西，一起共享著、理解著「打字其實也可以是一件很好玩的事情」，這麼小眾到不行的事，這種感覺真的太棒了。

其實我當初就是看到了 JN 的這篇〈關於嘗試拼音以外的中文輸入法〉，才覺得新學一個輸入法好像很有趣，就這樣開始了。

我現在要來對好幾個月前的自己說：沒想到吧，我這整篇文章都是用嘸蝦米打的呢！

Footnotes​

  1. 寫這篇才發覺我以往引用文章標題都是用〈〉，而不是《》，因為我當初覺得部落格中的貼文應該是篇名而不是書名，還是有點懶得改，所以我決定讓這個標點符號保有我自己的風格。 ↩

Photo by Mason Kimbarovsky on Unsplash

原本在我的興趣頁面裡的電影推薦，只有我覺得好看又值得推薦的電影，但是昨天我和蝦波看了一部超級微妙的電影《手札情緣》(The Notebook)，我不覺得不好看，但是從開始到結尾，吐嘈點實在太多了1，讓我萌生一個念頭，我想把所有我看過的電影都加進我的列表，再由我自己主觀打分數，應該會很有趣。

這樣我不就有自己專屬的 IMDB 排名了嗎？

現在就可以來點擊進入新的：電影推薦清單，看看這個全新更改的呈現方式啦（排版參考至 IMDB）

幫電影打分數​

開始實作後，我才發現這真的是一件不容易的事情，原先可能覺得某某電影值得這個分數，但是到後面看到了某部，又會覺得：「這部怎麼可能比上一部還好看！」然後陷入無限修改的矛盾。

我現在有個想法是，之後我可以把所有電影的 .js 資料做成一個像殘酷二選一的選擇器，這樣應該就可以幫助我自己「在主觀中最客觀」的打出分數了吧。

AI 寫作的生產力陷阱

2026年4月6日 · 閱讀時間約 5 分鐘 · 1493 字
資訊

這是我的「BlogBlog 同樂會 - 2026 年 4 月」投稿文章。本月主題是「生產力」！

2026-04-05 攝於臺灣文學基地

第一層陷阱：無限生產力​

在這個時代，任何人只要動動手指，AI 就能吐出無窮無盡的內容，我們擁有了無限的生產力，卻依舊貧乏於價值的判斷力。那些空洞、未經雕琢的 AI 文本正像雨後春筍般充斥在社群媒體與影音平台。

幸運的是，目前這些單純靠 ctrl c 與 ctrl v 產出的「數位垃圾」還不算太難認。

這種「隨手轉發 AI 產物」的行為，不就跟十五年前你阿姨在 LINE 群組裡狂發長輩圖一樣嗎？你覺得這很新奇有趣，但接收端感受到的只是「為什麼你要把這個沒用的垃圾丟給我？」。

不過我也可以同理狂發長輩圖的阿姨。轉傳長輩圖的人並不是惡意，你阿姨是真心覺得那圖片很好看的，並不是想要把「垃圾」丟給別人。問題只是阿姨對「內容價值」的判斷標準沒有隨時代更新，錯把垃圾當成了寶藏。

—— Wiwi 〈二手 AI 內容〉

第二層陷阱：AI 協作假象​

以往寫作是「思考」與「表達」的合體，但 AI 時代的寫作可以將兩者拆開進行。我們可以提出觀點、邏輯與初衷，讓 AI 負責執行——提供詞藻、串聯語句、優化語法，最後我們再消化成文。坦白說，我認同這種協作，這確實能激發靈感。

但這裡隱藏著一個更深的陷阱。

當 AI 給出的觀點比我原本想的更流暢、更有說服力時，我會無意識地開始「認同」那個被 AI 優化過的自己。我自以為在運用判斷力，實際上我只是在認同 AI 給出了感覺不錯的路線。這就像坐在一輛自動駕駛的車裡，手雖然握著方向盤，但導航早已設定好，即便我切換回手動駕駛，一字一句地寫，但行進的路徑其實還是跟著導航走。

在寫作這件事上，我並不是個熟門熟路的在地人。當 AI 帶我繞遠路時，我無法自信的辨別，最多只能發現「AI 叫我在高架橋上迴轉」這種低級錯誤。盲目相信著 AI 導航且抵達終點時，還會讓我對自己產生「方向感極佳」的錯覺，甚至優越地看向那些困在第一層陷阱裡的眾生。

第三層陷阱：我的觀點平平無奇​

「判斷力是最重要的」、「AI可以讓有判斷力的人，更有效率地產出文章」。

我不否定這種論點，理論上確實有可能。

但他們往往有意無意忽視了一點，那就是AI不會只「幫助」「有判斷力的人」，也會「幫助」沒有判斷力的人，以前所未見的效率，去量產文字垃圾。

—— 朱宥勳〈臉書貼文〉

AI 本質上是「毫無判斷力」的，它只是在機率模型下預測字句的關聯。然而，人類也可能是「毫無判斷力」的。

就算在與 AI 協作的過程中，我完美的留下了自己所有見解，但可能，一開始我們就把一個「誤解」交給 AI，而它會用引經據典、生動類比的方式，把這種似是而非包裝得煞有其事。接著，我們再把這些「絕妙幻覺」串聯起來——內容看似華麗，本質上卻是精心打扮成蘋果的爛梨子。

平庸的觀點不可怕，可怕的是對平庸一無所知。 在第二層陷阱久了，可能漸漸的放棄了獨立思考，卻還抱持著「我是個擅長運用工具的自由創作者」這種錯覺，生成著各式各樣庸俗的空洞內容。

嘗試在 AI 時代奪回自我​

我在想，該怎麼脫離這種生產力陷阱？不論是身為不想製造垃圾的作者，還是不想被垃圾淹沒的讀者。

我相信最好的辦法依舊是：「不停地寫，不停地思考」。

在開始經營部落格之前，我是只接收資訊而不產出想法的那種人。直到開始試著把腦中的念頭化為文字，我才發現自己的文筆有多匱乏、邏輯有多混亂。腦袋裡常是一團漿糊，必須藉由寫作一步步梳理，才能真正理解自己到底在想什麼。

使用 AI 幫助之後，我能夠有所產出了，因為 AI 將我的文字打理的看起來能上街見人。我曾一度以為自己有文字生產力，直到寫這篇文章的過程，我才意識到，阿，這不就是我自己嗎？原來我一直在陷阱邊緣徘徊。

說到底，在舊時代的爛文章，大家都能看出就是爛文章；而現今的爛文章，在 AI 的幫助下，變成了可能被「品味差」的人看不出來是爛文章罷了（小心不要變成連第一層 AI 垃圾都當寶的阿姨）。

我依然會使用 AI，在與 AI 協作的過程中，思考著哪些部份是屬於我的想法、我為什麼這樣想？想法和觀點當然沒有對錯之分，但卻有品味之別。我相信真正的「寫作判斷力」與「品味」需要經過大量的內化與掙扎才能培養出來。

或許這篇文章的觀點依舊庸俗，只是靠著 AI 的擦脂抹粉才讓你看得下去，但這就是我嘗試在 AI 時代奪回自我的過程。

謝謝你的閱讀，成為了我訓練自己的資料。

Winutil

2026年4月3日 · 閱讀時間約 4 分鐘 · 1007 字

這是在 Windows 系統上一個由大佬 Chris Titus 開發的超好用開源工具：Winutil，能一鍵去掉 Windows 煩人的追蹤、內建廣告、以及沒用的預裝軟體，還可以快速安裝很多實用應用，使用超簡易。

如何操作 WinUtil​

不需要下載安裝檔，直接透過終端機就能執行，將指令完整複製並在 PowerShell 中貼上，然後按下 Enter 即可。

irm christitus.com/win | iex

核心功能​

介面很乾淨簡潔，分為五個核心功能。

  1. Install (軟體安裝)

它像是一個軟體商店的自動化面板，透過微軟官方的 winget 引擎，讓你勾選多個軟體後一鍵安裝， 自動跳過「下一步、下一步」的視窗，也不會被夾帶廣告軟體，裡面還有「Upgrade All」按鈕，幫你把電腦裡所有軟體一次升到最新版，也可以找到許多不錯的軟體喔。

  1. Tweaks (系統優化)

修改登錄檔（Registry）和系統服務，來關閉不需要的功能，關閉微軟的數據追蹤，還可以強硬移除 Edge 和 Onedrive 等等煩人軟體，以及移除內建廣告。

  1. Config (功能配置)

管理 Windows 選用功能（Optional Features）和特定的修復腳本，開啟或關閉 WSL，重設 Windows Update、修復損壞的系統檔案的快速修復工具。

  1. Updates (更新管理)

可以將功能更新延遲 1 年，安全性更新延遲 4 天：基本的安全修補程式還是會裝，但會稍微晚幾天，以防剛發布的補丁有災情（我選 Security Settings）。

  1. Win11 Creator (客製化安裝檔)

製作一個極致簡約版的 Windows 11 安裝映像檔 (ISO)。

我的 Tweaks 設定​

Essential Tweaks中​

我選擇使用Standard，關掉沒用的後台監控，但不破壞系統功能（其中每一項都可以看到程式碼和作用）。

重要的幾項：

  • Delete Temporary Files：阻止微軟在後台偷偷上傳使用數據，節省一點點 CPU 與網路資源。

  • Set Services to Manual：把很多平常沒用到、卻開機就佔著記憶體的服務改成「有需要才啟動」

  • Enable End Task With Right Click：軟體當掉，直接在工作列圖示按右鍵選「結束工作」就好，不用再開工作管理員。

Advanced Tweaks 中​

  • Remove OneDrive：如果沒有在用微軟的雲端硬碟，把它刪掉會讓檔案總管乾淨很多，也不會在後台佔資源。

  • Remove Microsoft Edge：欠刪的 Edge，在這裡勾選後跑一次 Run Tweaks，就掰掰啦。

  • Disable Microsoft Copilot：這 AI 按鈕到底想幹嘛，趕快把它完整停用。

Customize Preferences 中​

  • 建議開啟：

  • Dark Theme for Windows：可以將系統調成深色模式。

  • Detailed BSoD：系統當機會顯示具體的錯誤代碼。

  • Num Lock on Startup：開啟。這樣開機時小鍵盤數字鍵就是預設開啟的。

  • Show Hidden Files：開啟時可以看到隱藏檔。

  • Verbose Messages During Logon：開機時會顯示「正在載入服務...」之類的文字，讓你清楚知道電腦現在在幹嘛。

  • S3 Sleep：能避開 Win11 關不掉的「Modern Standby」問題。

  • 建議關閉：

  • Bing Search in Start Menu：絕對要關！這會讓開始功能表搜尋時，不會跳出一堆亂七八糟的網頁搜尋結果，搜尋速度也會變快。

  • Recommendations in Start Menu：關閉會移除開始功能表下面那一區「推薦項目」，讓介面乾淨很多。

  • Mouse Acceleration：建議關閉。關閉滑鼠加速能讓游標移動是「線性」的，手感更穩定，打 FPS 遊戲也通常會設定關掉。

  • Cross-Device Resume：建議關閉。除非有好幾台電腦要同步開啟到一半的軟體，否則只是多餘的後台追蹤。

我主力用的系統還是 Windows，雖然沒有 Linux 那麼乾淨自由，但是小小設置一下就可以好用非常多，推薦給所有還在使用 Windows 的大家。

婚禮就是一種標會

2026年3月31日 · 閱讀時間約 3 分鐘 · 717 字

Photo by Foto Pettine on Unsplash

快 30 歲這個年紀，已經參加過不少朋友、同事的婚禮了，我覺得參加婚禮很開心，看到認識很久的好朋友、或是交情不錯的同事穿上禮服，在台上笑得很開心，那種為朋友獻上祝福的感覺很美好。但是我一直沒辦法同理「紅包文化」這個荒謬的陋習。

紅包其實是一場民間標會？​

紅包這東西到底是什麼？它真的跟傳統華人社會的「標會」沒什麼兩樣。

大家平常你出一點、我出一點，像是定期定額的投資。你參加別人的婚禮就是「繳會錢」，等到哪天輪到你自己結婚、標到會的時候，再一口氣把那筆錢拿回來。

但問題來了，標會是基於信任和財務需求，而紅包卻掛著「祝福」的名義。這就導致了一個很奇怪的心理：有些人可能真的把婚禮當成一種「回本」甚至「獲利」的手段。所以才會有超級久沒見的朋友，突然傳訊問你「最近好嗎？我要結婚了，這是我喜帖」，這是一種強制入會吧？

年度業績發表會​

除了紅包，婚禮的形式我也不喜歡。

聽過身邊的朋友，婚禮籌備到最後跟父母鬧翻。原因很簡單，因為這場婚禮根本不是為了新人辦的，而是父母的「面子展示會」。

某父親想請這輩子所有認識的點頭之交，某母親想邀請那些她十幾年沒聯絡的鄰居，最後場面搞得像是在慶祝某個地方官當選，還會有〇〇理事長、〇〇議員出現致辭，新人像兩個精緻的魁儡，在台上換了三套衣服、敬了幾十桌完全不認識的人的酒，然後下台連一口菜都沒時間吃。

婚禮應該也是現代飯店與婚宴公司的超成功行銷吧，大家都辦著一樣的流程、拍一樣的婚紗，吃著大同小異的合菜（永遠會出現的炸湯圓，為什麼炸湯圓可以算一道菜？）

送禮物​

古代婚禮中，親友通常不會像現代般直接贈送「現金紅包」，而是以贈送實物禮物為主，像是「賀禮」的行式，感覺有趣多了，就像倚天屠龍記裡，大婚之日趙敏送張無忌一束黃頭髮奪婚，好刺激呀。

如果我結婚的話，我想要只邀請很好的朋友來參加，然後大家隨意帶禮物來就好了，我也只想參加好朋友的婚禮，包出去的禮金沒有想要收回來的想法，這樣才是最純粹又真心的祝福吧。

選擇題

2026年3月27日 · 閱讀時間約 2 分鐘 · 249 字

Photo by Towfiqu barbhuiya on Unsplash

今天在 threads 上看到一個很有趣的選擇題。

1.（ ）你答對本題的機率是多少？

A.75%

B.100%

C.25%

D.0%

75%​

我的第一個直覺先刪掉 75%，因為選 75% 的話，代表隨便選三個都對，但答對了之後，代表答案是 75% ，另外兩個選項怎麼可能也對。

0%​

0% 有點意思，代表我怎麼選都是錯，這牽扯到了選擇題的定義問題，一定有一個答案嗎？或是可能四個都錯呢？

100%​

開始猶豫是不是要選 100%，因為我知道答案是 25%，而我選擇 100%，代表我知道我一定選對，所以答案是不是又變成 100% 了才對呢？

25%​

如果正確答案是 25%，而選項中剛好有一個 25%，那麼我隨機選到 25% 的機率確實是 25%。

最後我決定選 25%，因為考試不知道選什麼的時候就猜（C）肯定對啦！

Kobo 移除 DRM 指南

2026年3月21日 · 閱讀時間約 3 分鐘 · 738 字
注意

移除電子書平台 DRM 可能有風險，使用前請自行評估，本人僅供個人自用。

前言​

先來推一下昨天看的午夜場電影《極限返航》。這部由小說改編的太空科幻電影表現不俗，與多數太空電影相同，為了拯救全人類，主角前往太空尋找一絲渺茫的機會，展開一段前所未有的冒險。

與大家熟知的星際效應比較的話，走的是一個完全不同的基調與角色塑造，極限返航更偏向一點詼諧輕鬆的氛圍，敘事採雙線性，分別交代過去與現在，一點一點的完整故事脈絡，角色很討喜，看完會覺得很暖，充滿希望。

kobo-book-downloader​

在電影版看評價時，非常多人提到小說更好看，許多地方描寫的更完整，科學方面也著墨的更嚴謹，讓我非常想購入電子書來閱讀。

我研究了許久如何能正版購買再移除 DRM，這樣我就可以用自己習慣的閱讀 APP 在手機上閱讀了！最後選擇了在 kobo 平台買書後，利用 github 的開源工具移除 DRM，非常簡單。

移除 DRM 工具：kobo-book-downloader

With kobo-book-downloader you can download your purchased Kobo books and remove the Digital Rights Management (DRM) protection from them.

安裝與使用步驟​

  1. 前置準備

確保電腦已安裝 Python 3。

  1. 下載與安裝

取得程式碼，在 terminal 輸入：

git clone https://github.com/TnS-hun/kobo-book-downloader.git

進入資料夾：

cd kobo-book-downloader

安裝必要組件：

pip install -r requirements.txt
  1. 下載無 DRM 版本的 epub 檔

列出所有書籍：

python kobo-book-downloader list --all

第一次使用畫面會出現一段 URL 網址，將該網址複製並貼到瀏覽器打開，在 Kobo 網頁登入後，將網頁上顯示的代碼（Code）輸入回終端機。

下載所有書籍：

python kobo-book-downloader list --all

下載特定書籍： 如果你知道書籍的 ID（可從 list 指令取得）：

python kobo-book-downloader get /儲存路徑/書名.epub 書籍ID

這樣就大功告成啦！最後我用 Syncthing 將所有的電子書都同步到手機上，可以用自己習慣的閱讀程式真的太棒拉。

學會這個方法後，我又加了好多本想看的書在購物車了，感謝開發者的努力，你們又再次拯救了我的世界！諷刺的是，在學會如何移除 DRM 之前，即使我想看，但我根本不想買有 DRM 的版本，DRM 到底擋掉的是真的會看盜版的人，還是真的願意消費支持的人？

最後關於使用移除 DRM 到底算不算盜版？我是覺得不算，付費後如何使用應該是我的基本權利才對，雖然嚴格說起來，這樣就是盜版沒錯，但在看了 Ivon 的這篇〈隱私與盜版只有些微之差，看盜版總是受道德良心譴責〉後，我決定

壓力別太大，羞恥心的使用盜版就好了！

Canon AE-1​

寫這篇時才驚覺，我竟然所有畢旅都是用同一台相機拍的，而且我沒買過新相機或新鏡頭，全都是二手的耶（自豪）！
