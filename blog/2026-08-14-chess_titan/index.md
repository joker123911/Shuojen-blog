我在[〈西洋棋與我〉](/docs/chess/chess_start)中提到過，人生第一次接觸西洋棋這個遊戲，是小時候家裡的 Windows Vista 上內建的遊戲《Chess Titans》，小時候覺得 Vista 的遊戲也太漂亮了吧，遊戲畫面好有質感，尤其是接龍的畫面也比 XP 系統進步好多，真的漂亮，但後來 Vista 被評為數一數二差的版本就是後話了。

今天意外發現一個可以把 Windows 老遊戲裝回來的網站：[ Windows 7 Games for Windows 11 and Windows 10](https://win7games.com/#games)，好有回憶阿，除了[《Chess Titans》](https://zh.wikipedia.org/zh-tw/Chess_Titans)，還有這個[《Purble Place》](https://zh.wikipedia.org/zh-tw/Purble_Place)也很有回憶。

## Chess Titans Revenge

小時候不懂規則，只能看哪裡格子有發光就亂下，以前最讓我搞不懂的，就是兵為什麼老是卡住（原來因為兵的走法是直著走斜著吃！）所以連最菜的電腦也贏不了，現在就是復仇時刻啦，直接挑戰最高難度的電腦！

<img src={require('./difficulty.png').default} width="600" alt="img" />

其實最高難度的電腦還不弱，估計在 Chess.com 的 Rapid 可能有 1800 的實力，但據我無根據的猜測，這個電腦應該被設定成算棋的時間與深度有一定的限制，所以還是會有明顯失誤，對局面的理解也不太足夠，畢竟不是 [Stockfish](https://zh.wikipedia.org/zh-tw/Stockfish)，休閒導向已經很厲害了，一般沒訓練過的玩家，我覺得應該不太可能贏的了最高難度的電腦。

<img src={require('./chess.png').default} width="600" alt="img" />
