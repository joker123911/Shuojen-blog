王＋后對王＋車，理論上**白方必勝**，但實戰一點都不簡單：黑車只要待在黑王旁邊，后就很難直接吃到它，而且黑方一有機會就會用車**一直將軍**或**送車逼和**。

這種殘局最重要的局面叫 **Philidor 局面**：黑王在底線、黑車擋在王前面，白王跟黑王面對面。

你執白，想辦法吃掉黑車或直接殺王，試試看吧！

## 勝法說明

這個局面如果**輪到黑方走**，黑方就**沒有好棋**（Zugzwang，被迫走棋）：黑王動不了，黑車不管走到哪裡都會被后**將軍抽車**或直接殺王。

可惜現在是**白方先走**，所以白方要想辦法**把走棋權丟給黑方**：

- **后三角移動**：1.Qe5+ 將軍，黑王只能去 a8；2.Qa1+ 再將軍，黑王回到 b8；3.Qa5 后回到原來的格子。
- 三步之後，局面跟一開始**一模一樣**，只是變成**輪到黑方走**。
- 黑車離開黑王，后就**連續將軍**，最後一次將軍同時攻擊黑王和黑車（**抽車**），吃掉車之後回到[單后殺王](./queen-mate.md)。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 w - - 0 1"]
1. Qe5+ Ka8 2. Qa1+ Kb8 3. Qa5 Rb1 4. Qe5+ Ka7 5. Qd4+ Ka8 6. Qh8+ Ka7 7. Qh7+ Kb8 8. Qxb1+ Kc8 9. Qb4 Kd8 10. Qf8#`} />

:::tip[為什麼不直接吃車？]
黑車在黑王旁邊，有黑王保護。后對車要贏，靠的不是硬吃，而是**等黑車離開黑王**，再用將軍同時攻擊王和車。
:::

## 黑方的其他走法

輪到黑方走的 Philidor 局面，黑方怎麼走都會輸，常見的有下面幾種：

**車沿著橫線跑遠**：后連續將軍，把黑王趕到車的反方向，最後在 h7 將軍抽車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rh7 2. Qe5+ Ka7 3. Qa1+ Kb8 4. Qb1+ Ka7 5. Qxh7+ Ka6 6. Qb1 Ka5 7. Qb5#`} />

**車沿著直線往下走**：2.Qe5+ 將軍黑王，同時攻擊 b2 的車，黑王躲開之後就吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Rb2 2. Qe5+ Ka7 3. Qxb2 Ka6 4. Qa1#`} />

**黑王離開**：2.Qa6 **牽制**黑車，車不能離開 b7，下一步就直接吃車。

<White pgn={`[FEN "1k6/1r6/2K5/Q7/8/8/8/8 b - - 0 1"]
1... Kc8 2. Qa6 Kd8 3. Qxb7 Ke8 4. Qg7 Kd8 5. Qd7#`} />

## 小心逼和

黑方最大的機會是**逼和**：黑王被關在角落、自己已經沒有棋可以走的時候，黑車只要**送給白方吃**，就是和棋。

下面這個局面，白后 c7 已經把黑王關死了，黑方走 1...Rb6+!，白王吃車之後黑方**沒有任何合法的走法**，逼和。白王不吃車的話，黑車就繼續跟著白王一直將軍。

<Black pgn={`[FEN "k7/2Q5/2K5/8/8/8/1r6/8 b - - 0 1"]
1... Rb6+ 2. Kxb6`} />

:::tip[收網前先檢查]
把黑王逼到角落時，先想一想：**黑車送給我吃，黑王還有沒有棋走？** 沒有的話，就先換一步，讓黑王留一個空格。
:::

## 怎麼把黑王逼到邊線

黑王、黑車都在中間的時候，不可能馬上抽車，要先把黑王慢慢趕到邊線。記住下面幾個原則：

- **黑車會一直待在黑王旁邊**：黑車有黑王保護，后就吃不到；不要急著吃車，**Qxd5+ 這種吃車常常是送后**。
- **白王一直往前走**：跟[單車殺王](./rook-mate.md)一樣，白王要盡量跟黑王**對王**（面對面、中間隔一格），黑王才不敢往前。
- **后從遠處將軍**：后離黑王遠一點，黑王就碰不到后；后的將軍是用來把黑王**往後推**，讓白王有時間跟上。
- **黑車將軍時往前躲**：白王往黑王那一側躲，不要往後退，退回去就前功盡棄了。
- 黑王被推到邊線、沒有地方走的時候，黑方只好**移動黑車**，黑車一離開黑王，就有機會將軍抽車。

下面是殘局庫的下法，分成三個階段來看。

### 第一階段：把黑王推出中間

后連續從遠處將軍，黑王每退一步，白王就往前一步：Ke2、Ke3、Ke4，最後白王站到正中央，黑王被推到第 6 橫線。黑車找不到好的將軍，只能在遠處亂跑。

<White pgn={`[FEN "8/8/8/3rk3/8/8/8/3QK3 w - - 0 1"]
1. Qa1+ Ke4 2. Ke2 Rc5 3. Qb1+ Kd4 4. Qd3+ Ke5 5. Ke3 Rc1 6. Qd4+ Ke6 7. Qb4 Rg1 8. Qc4+ Ke5 9. Qh4 Ke6 10. Ke4 Rb1`} />

### 第二階段：趕到邊線

后繼續將軍，把黑王往王翼趕，白王跟在後面：Kf4、Kg4、Kg5。黑車從旁邊將軍時，白王都是**往前躲**（Kg4、Kf5），黑王就被擠到最後兩排。

最後黑方走 Rg7，把車放回黑王旁邊守著，這就是黑方典型的防守陣形。

<White pgn={`[FEN "8/8/4k3/8/4K2Q/8/8/1r6 w - - 0 1"]
1. Qh3+ Ke7 2. Qa3+ Kf6 3. Qc3+ Kg5 4. Qe3+ Kf6 5. Kf4 Rf1+ 6. Kg4 Kg7 7. Kg5 Kf7 8. Qd3 Rg1+ 9. Kf5 Rg7`} />

### 第三階段：封住底線，抽車

- **Qd8!**：后封住第 8 橫線，黑王 e6、f6、g6 被白王擋住，e7、e8、f8、g8 被后擋住，**黑王動不了**，黑方只好走車。
- 黑車離開 g7 之後，后將軍、白王再往前，黑車又得移動。
- 黑車跑到 h2，**Qe5+** 同時將軍黑王、攻擊 h2 的車，抽車，接下來就是單后殺王。

<White pgn={`[FEN "8/5kr1/8/5K2/8/3Q4/8/8 w - - 0 1"]
1. Qd8 Rh7 2. Qd5+ Kg7 3. Kg5 Rh2 4. Qe5+ Kf7 5. Qxh2 Ke6 6. Qa2+ Kd6 7. Qc4 Ke5 8. Kg6 Kd6 9. Kf6 Kd7 10. Qc5 Kd8 11. Ke6 Ke8 12. Qe7#`} />

:::tip[小心串打]
白王和白后**不要排在同一條直線或橫線上**。黑車從那條線將軍，白王一躲開，后就被黑車吃掉了。
:::

## 挑戰：從中間開始

學會怎麼趕黑王之後，從頭試一次！殘局庫最佳下法要 **31 步**才殺得了。

注意 d5 的黑車有黑王保護，**Qxd5+ 吃車就直接和棋了**。

<QueenVsRookBoard fen="8/8/8/3rk3/8/8/8/3QK3 w - - 0 1" />

照正常規則下，50 步內沒有吃子就是和棋，所以要邊下邊注意步數！
