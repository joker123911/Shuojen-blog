[西洋棋推坑](/docs/chess/introduce)裡沒有詳細介紹過規則，這篇文章參考維基百科的 [Rules of chess](https://en.wikipedia.org/wiki/Rules_of_chess) 與國際棋聯（FIDE）的規則，每個重點都搭配棋盤說明，看完就能開始自己的第一盤棋了。

## 棋盤與擺放

棋盤是 8×8 共 64 格，深淺交錯，不管實際是什麼顏色，淺色格都叫**白格**、深色格都叫**黑格**。

- 棋盤要擺成**兩邊玩家的右手邊角落都是白格**（white on right）。
- 雙方各有 16 個棋子：1 王、1 后、2 車、2 象、2 馬、8 兵。
- 最外側是車，往內依序是馬、象，中間兩格放后跟王，兵排在前面一整排。
- 后站在跟自己同色的格子：**白后在白格**(d1)，**黑后在黑格**(d8)，王站剩下那一格。

<ChessDiagram squares="Gh1,Ga8,Yd1,Yd8" caption="綠圈：雙方右手邊的角落都是白格；黃圈：后站在同色格" />

### 格子的名字

直的一排叫**直線**（file），從白方左手邊開始依序是 a～h；橫的一排叫**橫線**（rank），從白方這邊數過來是 1～8。每一格就用「直線＋橫線」命名，例如下圖藍色的 e 線和黃色的第 4 橫線交會在 **e4**。

<ChessDiagram fen="8/8/8/8/8/8/8/8 w - - 0 1" arrows="Be1e8,Ya4h4" squares="Ge4" caption="e 線與第 4 橫線交會在 e4" />

### 記譜

文章裡的棋盤都會用代數記譜法標出每一步，先認得這幾個符號就看得懂了：

| 符號 | 意思 | 例子 |
| :--: | :-- | :-- |
| K、Q、R、B、N | 王、后、車、象、馬（兵不寫字母） | Nf3：馬走到 f3；e4：兵走到 e4 |
| x | 吃子 | Bxc6：象吃 c6；exd5：e 線的兵吃 d5 |
| + | 將軍 | Qh5+ |
| # | 將死 | Qxf7# |
| O-O／O-O-O | 短易位／長易位 | |
| = | 升變 | e8=Q：兵走到 e8 升成后 |

## 基本規則

- **白方先走**，之後雙方輪流，每次走一步。
- 輪到你就**一定要走**，不能跳過（pass），就算每一步都會讓局面變差也一樣。
- 誰拿白棋規則本身沒有規定，比賽由賽會安排，平常下棋可以猜子決定：一手握白兵、一手握黑兵讓對方猜。
- 走到對方棋子所在的格子就是**吃子**，被吃的棋子拿下棋盤，不再回來。
- 不能走到自己棋子佔的格子；除了馬以外，**所有棋子都不能跳過其他棋子**。

## 棋子的走法

### 王（King）

往**任何方向走一格**。王是最重要的棋子，不能被吃，也**不能走到會被對方攻擊的格子**。

<ChessDiagram fen="8/8/8/8/4K3/8/8/8 w - - 0 1" squares="Gd5,Ge5,Gf5,Gd4,Gf4,Gd3,Ge3,Gf3" caption="王可以走到周圍 8 格" />

### 車（Rook）

**直走或橫走**，格數不限，但不能越過其他棋子。

<ChessDiagram fen="8/8/3P4/8/3R2n1/8/8/8 w - - 0 1" arrows="Gd4d5,Gd4f4,Gd4d1,Gd4a4" squares="Rg4" caption="往上被自己的兵擋住；往右可以吃掉 g4 的黑馬，但不能越過它" />

### 象（Bishop）

**斜走**，格數不限。象永遠待在同一種顏色的格子上，所以雙方各有一隻**白格象**和一隻**黑格象**。

<ChessDiagram fen="8/8/8/8/3B4/8/8/8 w - - 0 1" arrows="Gd4h8,Gd4g1,Gd4a1,Gd4a7" caption="象沿著斜線走，永遠在黑格上" />

### 后（Queen）

車加象，**直、橫、斜**八個方向都能走，格數不限，是威力最大的棋子。

<ChessDiagram fen="8/8/8/8/3Q4/8/8/8 w - - 0 1" arrows="Gd4d8,Gd4h8,Gd4h4,Gd4g1,Gd4d1,Gd4a1,Gd4a4,Gd4a7" caption="后可以往八個方向走" />

### 馬（Knight）

走 **L 形**：先直或橫走兩格，再轉 90 度走一格。馬是唯一能**跳過其他棋子**的棋子，被包圍也照樣跳得出去。每走一步，馬所在的格子顏色都會換一次。

<ChessDiagram fen="8/8/8/2PPP3/2PNP3/2PPP3/8/8 w - - 0 1" squares="Gb5,Gb3,Gc6,Ge6,Gf5,Gf3,Gc2,Ge2" caption="馬就算被自己的兵包圍，還是能跳到這 8 格" />

### 兵（Pawn）

兵的規則最多：

- **只能往前**，一次走一格，不能後退。
- 還沒動過的兵，第一步可以**一次走兩格**（中間那格要是空的）。
- **吃子是斜前方一格**，跟走法不一樣。
- 正前方有棋子擋住就不能前進，不管是自己還是對方的棋子。

<ChessDiagram fen="8/8/2p5/2P2n1r/6P1/8/4P3/8 w - - 0 1" squares="Ge3,Ge4,Gg5,Rf5,Rh5" caption="e2 兵第一步可以走一格或兩格；c5 兵被擋住不能動；g4 兵可以前進，也可以斜吃 f5、h5" />

### 子力價值

這不是規則，但下棋時常拿來衡量交換划不划算：

| 棋子 | 兵 | 馬 | 象 | 車 | 后 | 王 |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| 價值 | 1 | 3 | 3 | 5 | 9 | 無價 |

## 特殊走法

### 王車易位（Castling）

一步棋同時動王和車：**王往車的方向走兩格，車跳到王的另一邊**，把王藏到角落，也讓車出來參戰。王往 h 線那邊叫**短易位**（O-O），往 a 線那邊叫**長易位**（O-O-O）。

<White pgn={`1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. O-O d6 5. d3 Be6 6. Nc3 Qd7 7. Be3 O-O-O`} showEval={false} />

易位要同時滿足這些條件：

- 王和這隻車**都沒有動過**（動過再走回原位也不行）。
- 王和車**中間沒有任何棋子**。
- 王**現在沒有被將軍**。
- 王**經過的格子**和**落腳的格子**都**沒有被對方攻擊**。

注意最後一條只限制**王**，車經過的格子被攻擊沒關係。下圖黑象攻擊 f1，王會經過 f1，所以不能短易位；黑車雖然攻擊 b1，但長易位只有車經過 b1，所以可以長易位。

<ChessDiagram fen="1r2k3/8/8/8/2b5/8/8/R3K2R w KQ - 0 1" arrows="Ge1c1,Re1g1" squares="Rf1,Yb1" caption="紅：王會經過被攻擊的 f1，不能短易位；黃：只有車經過被攻擊的 b1，可以長易位" />

### 吃過路兵（En passant）

兵第一步**走兩格**，剛好停在對方兵的**正旁邊**時，對方的兵可以把它當作只走一格來吃：斜走到它**跳過的那一格**，再把它拿下棋盤。

- 只有兵能吃過路兵，被吃的也只能是兵。
- **只能在對方剛走完兩格的下一步吃**，錯過這步就不能再吃了。

下面黑兵 d7 一次走到 d5，停在白兵 e5 旁邊，白兵就可以走到 d6 把它吃掉：

<White pgn={`1. e4 Nf6 2. e5 d5 3. exd6`} showEval={false} />

### 升變（Promotion）

兵走到最後一橫線時，**必須升變**成同顏色的**后、車、象或馬**，不能留著當兵，也不能變成王。升變不受已經被吃掉的棋子限制，一方同時有兩隻以上的后也可以。

<White pgn={`[FEN "8/4P1k1/8/8/8/8/8/4K3 w - - 0 1"]
1. e8=Q`} showEval={false} />

絕大多數都是升后，但偶爾升成其他棋子比較好，叫做**低升變**。下面升后沒有將軍，黑后就跑掉了；升成馬卻能**將軍並同時抓后**：

<White pgn={`[FEN "8/3q1P1k/8/8/8/8/8/K7 w - - 0 1"]
1. f8=N+ Kg7 2. Nxd7`} showEval={false} />

## 將軍與將死

### 將軍（Check）

王被對方的棋子攻擊就叫**將軍**。被將軍的一方**下一步一定要解除將軍**，方法只有三種。以下圖為例，黑車在 e8 將軍白王（紅）：

1. **移動王**（藍），走到不會被攻擊的格子：白王可以走 d1、d2、f2，但 e2 還在黑車的攻擊線上，不能走。
2. **吃掉**將軍的棋子（綠）：白車沿著第 8 橫線吃掉黑車（Rxe8+），吃完還反過來將軍黑王。
3. 把棋子**擋**在中間（黃）：白象走到 e2 擋住黑車（Be2）。

注意：如果是被馬將軍，就沒辦法擋，因為馬是用跳的。

<ChessDiagram fen="R3r2k/8/8/8/8/8/8/4KB2 w - - 0 1" arrows="Re8e1,Be1d2,Ga8e8,Yf1e2" caption="紅：黑車將軍；藍：王躲開；綠：車吃車；黃：象擋在 e2" />

### 不能自己送將

任何讓**自己的王被攻擊**的走法都是違規的，所以：

- 王不能走到被攻擊的格子，**兩個王也不能相鄰**。
- 擋在王前面的棋子被**釘住**時不能離開，否則等於把王送給對方吃。

<ChessDiagram fen="4k3/4r3/8/8/8/8/4N3/4K3 w - - 0 1" arrows="Re7e1" squares="Re2" caption="白馬被黑車釘住，一動就會讓白王被攻擊，所以不能動" />

### 將死（Checkmate）

被將軍而**三種方法都解不了**，就是**將死**，被將死的一方輸棋。實際上王從來不會真的被吃掉，將死的那一刻棋局就結束了。

最常見的是**底線殺**：王被自己的兵關在底線，車一下去就死了。

<White pgn={`[FEN "6k1/5ppp/8/8/8/8/8/R5K1 w - - 0 1"]
1. Ra8#`} showEval={false} />

最快的將死只要兩步，叫做**愚人殺**，白方亂推兩隻兵，黑后直接殺王：

<Black pgn={`1. f3 e5 2. g4 Qh4#`} showEval={false} />

新手很容易被**學者殺**：白后和白象一起攻擊只有王保護的 f7。

<White pgn={`1. e4 e5 2. Bc4 Nc6 3. Qh5 Nf6 4. Qxf7#`} showEval={false} />

## 結束棋局

### 勝負

- 將死對方。
- 對方**認輸**。
- 對方**超時**（見下面比賽規則）。

### 和棋

#### 逼和（Stalemate）

輪到的一方**沒有被將軍**，但**一步合法的棋都走不了**，就是逼和，直接和棋。這是快贏的一方最常犯的錯：下面白方大優，走 Qf7 之後黑王沒有被將軍，卻哪裡都不能去，和棋了。改走 **Qf8#** 才是將死。

<White pgn={`[FEN "7k/8/6K1/8/8/8/5Q2/8 w - - 0 1"]
1. Qf7`} showEval={false} />

#### 子力不足（死局）

雙方**用任何合法的走法都不可能將死對方**時，直接和棋，例如：

- 王對王。
- 王＋象對王。
- 王＋馬對王。
- 王＋象對王＋象，而且兩隻象在同顏色的格子。

#### 三次重複

**同一個局面**（同一方要走，棋子位置一樣，易位和吃過路兵的權利也一樣）出現**第三次**時，可以宣告和棋，不必連續出現。最常見的是**長將**：一直將軍讓對方擺脫不了。下面黑方多了一車，白方卻靠后不停將軍，同一局面重複三次就和棋：

<White pgn={`[FEN "6k1/6p1/5p2/8/8/r7/1q2QPPP/6K1 w - - 0 1"]
1. Qe8+ Kh7 2. Qh5+ Kg8 3. Qe8+ Kh7 4. Qh5+ Kg8 5. Qe8+`} showEval={false} />

#### 五十步規則

雙方**各走 50 步**，期間都沒有吃子、也沒有動兵，就可以宣告和棋。

#### 自動和棋

三次重複和五十步規則都要**有人提出**才算，沒人提就繼續下；但同一局面重複**五次**，或雙方各走 **75 步**沒有吃子和動兵，就不用宣告，**直接和棋**。

#### 協議和棋

任何一方都可以**提和**，對方同意就和棋。正式比賽要在自己走完棋、按鐘之前提出。

## 比賽規則

平常線上下棋，網站會幫你處理好這些事，但實體比賽有幾條一定要知道：

- **摸子動子**：故意碰了自己的棋子就**一定要走那個棋子**；碰了對方的棋子，能吃的話就**一定要吃它**。只是想把棋子擺正，要先說「**我調整一下**」。
- **放手就算**：棋子拿在手上還沒放開時，可以改放到這個棋子的其他合法格子；一旦**手放開**，這步就確定了，不能反悔，就算走錯也一樣。王車易位要**先碰王**再動車，先碰車的話就只能走車、不能易位了。
- **用同一隻手**走棋和按鐘，走完棋才按鐘。
- **超時判負**：自己的時間用完就輸，但如果對方剩下的子力**怎麼走都不可能將死你**（例如對方只剩單王），就是和棋。
- **違規走法**：走了違規的棋要收回重走，而且**碰到哪個棋子就要盡量走那個棋子**。依 FIDE 規則，第一次違規**對方加時**（慢棋加 2 分鐘，快棋、超快棋加 1 分鐘），**第二次違規直接判負**。
- **記譜**：慢棋比賽要用代數記譜法把每一步寫在記錄紙上。
